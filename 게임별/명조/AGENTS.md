# 명조 클라이언트 분석

명조를 분석할 때는 이 폴더를 기준으로 작업한다. 패키지 어댑터, 파밍 계산기, 보고서 생성기, 테스트와 이전 회차가 여기에 있다. 공통 절차와 6관점 검토는 프로젝트 루트의 [AGENTS.md](../../AGENTS.md)를 따른다.

- Windows PAK v12의 확인 범위와 의존성은 [명조 분석 안내](README.md)를 읽는다. 기존 로컬 회차와 입력 해시는 `콘텐츠/명조/클라이언트분석/설계결과.json`에서 찾는다.
- 설치본에서 비용·환급만 확인했으면 `analyzed_partial`로 기록하고 별도 분석 입력의 경로·SHA-256을 남긴다. 지급량·확률의 후속 조사는 패키지 색인, 테이블 등록부, 관련 스키마와 소비 코드를 대조한다.
- 공개 확률과 과거 실측을 사용한 파밍은 `도구/명조_파밍계산.py`로 계산한다. 선별·환급·재화 지급 묶음을 반영하며 기록한 버전·표본·조건을 함께 보고한다. 후보 획득·전투 시간과 행동력 환산일을 구분한다. 천장과 재구성은 이 계산의 범위 밖이다.
- 전달본은 [명조 보고서 모음](index.html)에서 연다. 중부 평원 무음구역 단일 보고서는 저장소에 포함된다. 로컬에서 생성한 문서 모음은 `문서/명조/index.html`, 잔향 정제실 가상 제안은 `문서/명조/제안서/신규던전_잔향정제실_인터랙티브.html`에 있다.
- 과거 회차에는 분리 전의 절대 경로와 당시 파일의 해시가 들어 있다. 이 작업 사본에는 해시 검증에 필요한 이전 경로가 남아 있다. 새 회차의 경로는 이 폴더를 기준으로 기록한다.
- 게임별 검증은 이 폴더에서 `python3 -m unittest discover -s tests -v`로 실행한다. 공통 계산기는 프로젝트 루트에서 별도로 검증한다.
