# 모델과 집계 로그 검증

이 파일에서 세 단계 위가 프로젝트 루트다. [AGENTS.md](../../../AGENTS.md)와 [데이터 명세](../../../데이터_명세.md)를 읽는다.

1. 사용자가 지정한 입력을 우선 사용한다. 경로가 없으면 대상의 최신 `설계결과.json`에 기록한 최종 입력을 찾아 어느 모델인지 밝힌다. 미해결 초안을 확정 데이터로 부르지 않는다.
2. 아래 명령을 실제 실행한다. `--out`에는 새 결과 경로를 사용한다. 종료 코드 2는 계산 오류가 아니라 목표 미설정·미충족이다.

```bash
python3 도구/밸런스.py validate "<모델>"
python3 도구/밸런스.py simulate "<모델>" --out "<새 계산 결과>" --strict
```

3. 로그가 있으면 데이터 명세의 집계 CSV 계약을 확인하고 다음을 실행한다. 개인 로그가 제공됐으면 원본을 보존하며 식별자 없는 별도 집계 사본을 준비한다. 누락 필드를 0으로 꾸미지 않는다.

```bash
python3 도구/밸런스.py logs "<모델>" "<집계.csv>" --out "<새 로그 결과>"
```

4. 입력 형식·모의 목표 충족·관측과의 차이를 구분해 보고한다. 기간·난이도·최초 클리어 비중 차이는 자동 보정되지 않는다. users 합계는 유저-일이며 순유저나 잔존율이 아니다.
5. 로그 없이 실행했다면 모의 검증이라고 밝힌다. 실측을 기존 모델에 자동 덮어쓰지 않는다. 조정까지 요청받았으면 [content-balance](../content-balance/SKILL.md)로 새 변경안을 만든다.
